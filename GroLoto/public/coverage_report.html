Description

GroLoto est une application web complète de gestion d'événements de loto développée avec Symfony 7.3. Elle permet la gestion des bénévoles, mécènes, stocks, tâches, et la planification des événements.

Étapes de Déploiement
🐳 Déploiement Docker (Recommandé): 

# 1. Clone du projet
git clone https://github.com/Rlima-collab/Groloto.git
cd Groloto/GroLoto

# 2. Construction et démarrage
docker compose up --build -d

# 3. Accès à l'application
# Application: http://localhost:8080
# MailPit: http://localhost:8025
🖥️ Déploiement Manuel: 

# 1. Prérequis: PHP 8.2+, Composer, SQLite3

# 2. Installation
composer install
php bin/console doctrine:database:create
php bin/console doctrine:migrations:migrate

# 3. Assets
php bin/console asset-map:compile

# 4. Lancer le serveur
symfony server:start
